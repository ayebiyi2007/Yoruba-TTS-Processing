# Yoruba-TTS-Processing
A long term personal project of mine to develop a basic yet useful tool for helping Yoruba learners improve their pronunciation of written Yoruba text.

For a quick demo, go to https://htmlpreview.github.io/ and insert the path https://github.com/ayebiyi2007/Yoruba-TTS-Processing/blob/main/index.html

Future Development Goals:
- Overhaul Web Synthesis API with custom made library
- Find and implement Yoruba dictionary
- Review and improve upon accessibility
